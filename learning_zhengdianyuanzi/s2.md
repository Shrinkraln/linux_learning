2. sudo vim /etc/vsftpd.conf 修改local_enbale=YES write_enable=YES
3. sudo /etc/init.d/vsftpd restart 重启
4. linux安装服务器，win安装客户端

## 5. GNU汇编指令
1. 基本格式是 label:command @comment
2. 段从段名开始，到下一个段名结束
   1. .data .bss .text .rodata
   2. .section .mysection自定义一个段名
3. 常见的伪操作
   1. .byte .short 16 .long 32 定义数据
   2. .equ 赋值
   3. .align 数据对齐
   4. .end
   5. .global 定义全局符号
4. 处理器内部传输数据
   1. MOV R0 ,R1
   2. MOV R0 ,#0x01
   3. MRS R0 ,CPSR
   4. MSR CPSR R0
5. 读取RAM数据到处理器
   1. LDR R0 ,=0x0001   同样是立即数；只是单纯存放
   2. LDR R0 ,[R0]      从已经存放地址的寄存器加载
6. 存储处理器到RAM
   1. STR R0 ,[R1]      RO存进R1指向的地址
7. a=b 赋值
   1. ldr r0, =0x01
   2. ldr r1, [r0]
   3. ldr r0, =0x02
   4. str r1, [r0]
8. 压栈出栈
   1. push {R0-R3,R5}
   2. pop {R0-R3,R5}
9. 跳转
   1.  b func
   2.  bx R0
   3.  bl func       会保存跳转前地址到LR
   4.  blx R0
## 6. 编译
1. arm-linux-gnueabihf-gcc -g -c led.s -o led.o    -g 产生调试信息 -c 选择汇编文件 -o 选择编译产生的文件名
2. arm-linux-gnueabihf-ld -Ttext 0X87800000 led.o -o led.elf      -Ttext 选择连接的起始地址 -o 选择连接产生的文件名
3. arm-linux-gnueabihf-objcopy -O binary -S -g led.elf led.bin       -O 选择输出的格式
