## 1. 目录结构
1. linux里有最高目录/，所有的文件都从此目录开始
2. 而常用的~/是/home/imiam/路径的缩写
3. /bin 可执行二进制文件
4. /boot ubuntu 内核启动文件
5. /dev 设备驱动文件。设备都是以文件的形式存储的
6. /etc 配置文件
7. /lib 库文件
8. /media 可拔插设备挂载的文件。如u盘接入之后是在此目录下读取文件，但是对u盘的操作是在/dev目录下的文件实现
9. /mnt 可选挂载点
10. /opt 可选存储文件
11. /root 
12. /proc 在内存而不是flash的临时虚拟文件，如系统运行信息
13. /run 同样的内存的虚拟文件，存放系统运行状态
14. /sbin 系统二进制文件
15. /srv 服务
16. /sys 同样的内存虚拟文件，记录内核信息
17. /temp 临时文件
18. /usr UNIX Software Resource 系统软件资源
19. /var 变化文件，如日志文件\

## 4. 磁盘管理
1. 选择FAT32格式的u盘
2. /dev/sda表示u盘；/dev/sda1表示u盘的第一个分区
```shell
df      #查看磁盘空间
du [files/dir]      #查看文件目录大小
#--max-depth=1 只进入y一层目录，子目录只显示总容量
umount /media/imain/Shrinkraln  #取消挂载，此时挂载点已经不能再读取，但是/dev还是保留设备
mount -o iocharset=utf8 /dev/sda1 /mnt/Shrinkraln      #挂载设备分区,并且指定编码 
sudo fdisk -l        #查看磁盘分区
sudo fdisk /dev/sda #对设备进行分区而不是对分区sda1进行操作
#此操作的前提是umount取消挂载，后续操作结束之后都需要w写入
#d删除扇区
#n添加扇区：p主扇区 1分区号 2048起始扇区编号 +50G分区大小
#一个扇区512B大小，起始扇区编号实现分区起始对齐
#创建分区需要修改签名fat32；exfat更现代化但是嵌入式兼容性不如fat32
sudo mkfs -t vfat /dev/sda1 -L "IMIAM"    #格式化为fat32
sudo fatlabel /dev/sda1 IMIAM   #修改分区名称

#制作share
sudo apt install exfatprogs
sudo mkfs.exfat -L "SHARE" /dev/sda1
sudo parted /dev/sda set 1 msftdata on
```
## 5. 压缩和解压缩
1. 常见的压缩格式：.tar .tar.bz2 .tar.gz
2. .tar.gz 需要gzip压缩工具
3. .tart.bz2 需要bzip2
4. .tar 只是打包不包括压缩，压缩需要指定使用gzip或者bzip2
```shell
gzip a.c        #将a.c压缩为a.c.gz，并替换
gzip -d a.c.gz  #解压缩，并替换
gzip -r [dir]   #将目录下的文件进行分别压缩，不生成文件夹的压缩包，递归压缩
bzip2 -z a.c    #压缩
bzip2 -d a.c.bz2
tar [options] [tarobj] [sourceobj] -C [dir]   #压缩和打包
#-c 压缩 -x 解压缩 -j bzip2压缩 -z gzip压缩 -v 显示过程 -f 递归
#f一定是在最后
#-C指定解压缩存放的目录，是整个压缩包的目录
tar -vczf tst.tar.gz tst
tar -vxzf tst.tar.gz -C /out/   #需要提前创建存储目录
    -vcjf
    -vxjf
```
## 6. 用户和用户组

   2. root用户

3. /etc/shadow 存储用户密码

## 11. Make和Makefile
1. make工具只编译修改的部分的文件，避免大规模文件的重新编译
2. 通过makefile文件控制
3. 格式为
```makefile
tartget:dependence
   command

main:main.o input.o
   gcc -o main main.o input.o
input.o:input.c
   gcc -c input.c
main.o:main.c
   gcc -c main.c

#make clean
clean:
   rm *.o
   rm main
```
4. command为tab键开始
5. 变量赋值
   1. =赋值；右变量有效值是最后的值
   2. := 右边量有效值是当即的值
   3. ?= 左边量未赋值才赋值
   4. += 字符串添加元素
6. 通配符%
7. 自动变量
   1. $< 依赖项的第一个文件
   2. $@ 目标文件
   3. $^ 所有依赖项
8. makefile里面使用shell指令会显示指令本身，添加@前缀修饰将不显示指令
```makefile
object=main.o input.o
object+=func.o
target=main
$(tartget):$(object)
   gcc $^ -o $@
%.o:%.c
   gcc -c $<
```
9. 伪目标
   1.  不需要生成目标，而是需要执行其指令
   2.  默认伪目标名称是不和该目录下其他文件名称重复的；如果有，添加.PHONY=clean 声明
```makefile
.PHONY:clean
clean:
   rm *.o
   rm main
```
