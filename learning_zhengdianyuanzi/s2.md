## 1. 使用FTP服务
1. sudo apt install vsftpd
2. sudo vim /etc/vsftpd.conf 修改local_enbale=YES write_enable=YES
3. sudo /etc/init.d/vsftpd restart 重启
4. linux安装服务器，win安装客户端
## 2. NFS和SSH
1. sudo apt install nfs-kernel-server portmap
2. sudo vim /etc/exports 添加 /home/imain/linux/nfs *(rw.sync.no_root_squash)
3. sudo /etc/init.d/nfs-kernel-server restart 重启
4. sudo apt install openssh-server
